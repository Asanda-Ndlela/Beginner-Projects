# Beginner Projects

These are my very first projects in becoming a Java Developer.

This repository contains beginner-friendly Java applications created while learning Java programming, JavaFX, and application development fundamentals.

## Projects

### Calculator

A JavaFX calculator application with a graphical interface that performs basic arithmetic operations.

**Technologies:** Java, JavaFX, CSS, FXML

### Number Guessing Game

A JavaFX number guessing game that challenges the player to guess a randomly generated number.

**Technologies:** Java, JavaFX

## Technologies

- Java
- JavaFX
- CSS
- FXML
- Maven

### Prerequisites

- Java Development Kit (JDK) 17 or later
- Maven
- A Java IDE such as IntelliJ IDEA or Eclipse
